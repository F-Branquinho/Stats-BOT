# Stats BOT Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Discord bot plus website that collects each linked player's CS2 matches from Leetify, shows per-server leaderboards and posts a monthly top 10 / awards report.

**Architecture:** One Node.js process (CommonJS) running the discord.js client, an Express site and node-cron jobs, with SQLite (better-sqlite3) as storage. Pure modules (`rating`, `periodos`, `leaderboard`, `report`) hold the rules and are unit-tested; I/O modules (`leetify`, `collector`, `bot`, `web`) take their dependencies as parameters so tests can pass fakes. Setup, OAuth, sessions and deploy are adapted from `../Discord-BOT`.

**Tech Stack:** Node.js ≥ 18 (Docker image node:22-alpine), discord.js 14, express 4, node-cron 3, better-sqlite3 11, dotenv 16, `node:test`.

**Spec:** `docs/superpowers/specs/2026-10-22-stats-bot-design.md`

## Global Constraints

- Follow Discord-BOT's style: CommonJS, 4-space indent, single quotes, **Portuguese identifiers**, English comments, English user-facing text (except the PT report/replies from `i18n.js`), console logs with emoji prefixes (`✅`, `❌`, `⚠️`).
- Timezone for every month boundary, schedule and report: `Europe/Lisbon`.
- Collection slots: every 30 min from 16:00 to 04:00 Lisbon (25 slots: 16:00 … 23:30, 00:00 … 04:00), 2 s between Leetify requests.
- Default daily request budget: 3000. On 429: stop the run, wait `Retry-After` seconds or 10 minutes.
- Leetify base URL `https://api-public.cs-prod.leetify.com`; optional key sent as header `_leetify_key`.
- MVP eligibility: ≥ 5 counted matches in the month. Points = result (3/1/0) + HLTV 1.0 tier bonus (0–5). Tie-break: wins, then avg HLTV rating, then matches.
- Report: 1st of month 12:00 Lisbon, top 10 by points (1st = 🏆 MVP), then 🔫 🎯 🧠 💡 🤦 🎮 awards; one report per guild per month.
- Commit messages in Portuguese, **no Co-Authored-By or any Claude trailer**.
- Secrets never committed: `.env` and `data/` are git-ignored.

## Review Focus

1. **Two linked friends in the same match** → one `matches` row, two `player_matches` rows; re-collecting inserts nothing (Task 3 test `mesma partida para dois jogadores`).
2. **Month boundary with DST** — `2027-03-31T23:30:00Z` is 1 April 00:30 in Lisbon (UTC+1 since 28 March) → April; `2026-10-31T23:30:00Z` is 31 October 23:30 (UTC+0 since 25 October) → October (Task 6 tests pin both).
3. **Broken match data** (`rounds_count` 0 or missing fields) → no exception, `counted = 0` (Task 2 test `partida sem rondas`).
4. **Member left the server** → not in that guild's table, `/top` or report (Task 9 test on `membrosLigados`).
5. **Steam account already linked to another Discord user** → link refused with a message, original link kept (Task 3 test `steam já ligada`, used by Task 10).
